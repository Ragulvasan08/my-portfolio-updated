# 🌌 Code Universe - Portfolio

A unique space-themed portfolio website that presents your projects, skills, and experience as a navigable universe. Built with Next.js, React Three Fiber, and Framer Motion for stunning animations and interactions.

## ✨ Features

- **Interactive Space Navigation** - Navigate through your portfolio like exploring a universe
- **Animated Starfield Background** - Dynamic star animations with twinkling effects
- **Central Star Hero Section** - Eye-catching introduction with orbital animations
- **Constellation Navigation** - Unique map-style navigation system
- **Planet Projects** - Each project represented as a unique planet
- **Responsive Design** - Fully responsive across all devices
- **Smooth Animations** - Powered by Framer Motion
- **Glass Morphism UI** - Modern glass effects and gradients
- **Custom Cursor Effects** - Interactive mouse following effects
- **Performance Optimized** - Built with Next.js 14 for optimal performance

## 🚀 Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type safety and better development experience
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React
- **Three.js** - 3D graphics (planned for advanced features)
- **React Three Fiber** - React renderer for Three.js

## 📦 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/yourusername/portfolio-universe.git
   cd portfolio-universe
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   # or
   yarn install
   \`\`\`

3. **Start the development server**
   \`\`\`bash
   npm run dev
   # or
   yarn dev
   \`\`\`

4. **Open your browser**
   Visit [http://localhost:3000](http://localhost:3000) to see your universe!

## 🛠️ Customization

### Personal Information
1. Update `src/app/layout.tsx` - Change metadata (title, description)
2. Update `src/components/sections/HeroSection.tsx` - Change name and title
3. Add your projects, skills, and experience data

### Colors & Styling
1. Modify `tailwind.config.js` for custom colors
2. Update `src/app/globals.css` for global styles
3. Customize component styles in individual files

### Content Sections
Each section is designed to be modular:
- **Hero**: Central star with your introduction
- **About**: Your story and background  
- **Projects**: Interactive planet representations
- **Skills**: Constellation of technologies
- **Experience**: Timeline nebula
- **Contact**: Communication hub
